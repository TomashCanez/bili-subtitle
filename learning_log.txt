项目目标
--------
做一个面向 Windows 用户的小工具：批量读取 B 站视频链接，通过 yt-dlp 只下载可用字幕，排除弹幕，并保存为便于后续阅读/AI分析的文本文件。

这个项目同时承担第二个目标：从零学习如何创建和维护一个规范的 GitHub 开源项目。

学习原则
--------
1. 每次只引入少量 Git/GitHub 概念。
2. 重要 Git 命令优先由学习者本人执行，而不是全由 AI 代劳。
3. 每完成一个阶段，都先用 git status / git diff 检查发生了什么。
4. 不把 Cookie、登录凭证、真实下载字幕等个人/版权内容提交到公开仓库。
5. 每个 Commit 尽量只表达一个清晰变化。
6. 项目功能与 GitHub 工作流一起推进，而不是“代码写完后才学 Git”。
